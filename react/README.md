# React Portfolio Project

This project was bootstrapped with [Vite](https://vitejs.dev/) and React.

## Getting Started

### Available Scripts

In the project directory, you can run:

#### `npm run dev`

Runs the app in development mode. Open [http://localhost:5173](http://localhost:5173) to view it in your browser.

#### `npm run build`

Builds the app for production to the `dist` folder.

#### `npm run preview`

Preview the production build locally.

## Project Structure

- Components are located in `src/components/`.
- Static assets (images, etc.) should be placed in `public/`.

## Customization

- Update the content and images in the components to match your portfolio.
- Use Bootstrap for styling (add via npm or CDN).
